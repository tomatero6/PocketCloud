# PocketCloud
PocketCloud（口袋云）是一个将闲置安卓设备转化为-轻量级的个人 NAS 系统-的安卓软件
基于 Android 的全栈式个人移动存储与硬件管理解决方案
将闲置安卓设备转化为高性能网络附属存储 (NAS) 的核心驱动引擎。
(我不会用github发布，所以只能把两个源代码压缩包放出来了）
1. 项目概述 💡
缘起：买硬盘送手机
2026年4月3日，pdd最便宜的1tb硬盘价格来到了806块，而这个价格已经有几款二手1tb手机可以选择。我最近恰好想买一部新旧手机，而realme gt neo 5是我大学时的白月光。于是我花了850元购买了一台16+1t的neo5，相当于买1t硬盘送手机。我在想这1t的手机存储要是能利用起来就好了，拿来存数据。手机数据管理起来还是不方便，在数字化时代，个人数据碎片化严重。因此...

“口袋云”旨在通过极简的部署方式，挖掘闲置安卓设备的硬件价值。它不仅仅是一个文件传输工具，更是一个**“软件定义存储”**的典型应用。它通过将手机底层存储、硬件多媒体解码以及文件系统能力封装为标准的 RESTful API，将任意安卓设备转化为一台功能完备的轻量级 NAS。本软件承担了服务端协议实现、硬件资源调度、多媒体实时转码等核心任务，配合前端控制台，为用户提供私有化的云端存储体验。用户可以通过任何设备的浏览器（Web 端）对手机进行深度管理、数据同步及多媒体点播。

“口袋云”意味着把NAS的云端存储功能装进口袋“触手可及”。‘Pocky’和‘Pockit’由单词’Pocket’改编，使app名称更具“轻量化”和国际化

2. App 介绍与核心功能 🚀

📡 Pocky —— 服务端 (存储端)
承担整个系统的“大脑”职能，提供高可靠的后台服务。
🚀 极速文件处理中枢
对象级操作：支持递归删除、跨卷拷贝、移动，兼容内置存储与外置 OTG 硬盘。
断点续传与 MD5 校验：内置 RandomAccessFile 分片写入机制，支持 offset 偏移量续传，确保数据完整性。
实时文件索引：深度集成 Android MediaScanner，上传后自动触发系统扫描，实现相册“即传即看”。
🖼️ 多媒体智能分发
动态缩略图引擎：实时生成并缓存 JPEG 缩略图，支撑数千张照片的极速预览。
智能 MIME 映射：自动识别 20+ 种格式（FLAC, WebP, MOV 等），确保跨端兼容。
🕹️ 硬件级 API 开放
反向控制协议：开放 play-on-server 接口，允许远程指令控制手机本地音频播放。
系统参数调度：远程调节物理音量、切换播放状态，实现软硬一体化交互。
🛠️ 稳定性保障
Ktor 3.0 + Netty：异步非阻塞架构，低配机型亦可应对高并发。
前台服务 (Foreground Service)：适配 API 34+，确保进程不被系统回收。

🌐 Web 端 —— 全功能全平台控制台
内置于服务端的响应式交互界面，跨平台免安装访问。
极简浏览器：支持树状目录浏览、多盘符切换。
流式预览：支持音视频 HTTP 206 范围请求，实现 4K 原画秒开与拖拽。
云端批处理：支持在客户端发起远程 .zip / .tar.gz 压缩与解压，无需下载到本地。
远程音箱模式：Web 端一键点歌，手机硬件直接解码播放。

📱 Pockit —— 客户端
轻量化云端资源管理工具，通过原生 UX 将能力“装进口袋”。
🔄 数据备份：支持增量备份相册或指定文件夹，具备完善的断点重试机制。
🚀 系统级“分享上传”：打破 App 孤岛，在浏览器或其他应用中通过系统分享菜单即可直传文件至服务端。
📂 极致体验：优化的长列表渲染，在大数据量下保持高帧率滑动。

3. 技术栈详情 🛠️
核心语言: Kotlin (Coroutines + Serialization)
Web 服务器: Ktor Server 3.0.3 (Netty 引擎)
通信协议: HTTP/1.1, WebSocket, JSON (Kotlinx Serialization)
多线程方案: IO 密集型协程调度 (Dispatchers.IO)
技术亮点:
架构解耦：RESTful API 设计，具备极强的向前兼容性。
状态订阅：WebSocket 监听服务端动态，实现秒级状态更新。
UI 优化：虚拟列表技术，支撑万级文件流流畅滚动。
4. 核心优势 ✨
零成本入场：无需购置昂贵 NAS，一部旧手机即刻变身。
零配置部署：自动探测局域网 IP，一键启动服务。
极致轻量：服务端仅几十 MB，内存占用极低。
能耗比极高：ARM 架构下，待机功耗仅 1-2W（对比传统 NAS 15-30W）。
高安全性：数据全本地存储，点对点传输，无隐私泄露风险。

5. 应用场景 🎯
旧机利用：将淘汰的手机插上电源和 SD 卡，瞬间变成 1TB 的私人云盘。
跨端办公：无需数据线，在电脑浏览器直接整理手机里的截图和文档。
家庭影音：手机存储影音资源，平板/电视通过 Web 界面远程点播。
